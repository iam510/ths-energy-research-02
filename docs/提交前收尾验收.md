## 本轮修复

1. 模型无引用摘要不直接展示。比较摘要由通过校验、实际保留的首个可比项与边界项重新整理；丢弃错误项后不会遗留原摘要。两个可复现反例均加入测试。
2. 候选复核不默认产品。对“拟新增、预计未来、尚未开展”等表述，服务端拒绝授予已开展业务或收入信用；要求按规划记录或拆成明确事实。关键词规则仍可能漏报和误报。
3. 新材料可指定取代同公司当前有效旧依据。旧原文不删除，当前归属、比较指标及AI输入排除旧依据；撤回更正材料恢复直接被取代依据。替代链需从最新项依次撤回，避免错恢复。不得跨公司、自身或取代已停用材料。
4. 导入阶段仍剥离自报metric。新增财务指标另填原披露值、单位、币种和范围；数值、正负号及单位须在核对摘录中出现，美元/韩元不能误匹配为人民币。混合口径收入仅作背景，复核状态明确为个人、未经独立核验。
5. 历史版本的导入和复核控件只读；再次提取材料前清空旧候选及调用凭证，避免失败后误用上一次结果。
