# 模型接入说明

当前按用户2026-10-30的明确选择，先完成离线版本，稍后配置真实AI。当前不是运行时LLM产品，不能将规则文本冒称实时AI生成。

`POST /api/analyze` 接受 `companyId`、`scenarioId`、`mode`。离线模式返回结构化传导节点、事实、引用、条件、反向因素及信息缺口；`mode: live` 返回503和未调用模型说明。前端展示“离线规则模式”。

后续接入步骤：选择有权限的模型服务，在服务端配置密钥和模型名称，基于已核验的Evidence集合生成结构化结果，校验引用及数值，并执行真实调用测试。可选择AI Gateway，也可在确认接口协议后使用兼容服务。当前未安装、调用或验证模型SDK，不承诺仅填写环境变量即可获得未实现的实时功能。

结构化输出应包含 `facts[{text,evidenceIds}]`、`nodes[{kind,title,text,evidenceIds}]`、`conditions`、`reverse`、`gap`。事实节点必须有有效引用，引用存在也不等于原文真正支持结论，关键材料仍需复核。新增材料的AI提取只生成候选，不能由模型自行授予“已核验”状态。

密钥只能保存在本地忽略的环境文件或托管平台的服务端secret中，不得写入前端、仓库或提交包。未配置、超时、无效JSON、悬空引用、来源冲突时明确报错或保留历史版本，不伪装为成功调用。
